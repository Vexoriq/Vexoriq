Faqat sayt egasi uchun — o'zgarishlar barcha tashrifchilarga ko'rinadi

1. GitHub ulanishi

Token qayerdan olinadi: GitHub → profil rasmi → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token. "Repository access"da faqat shu repo'ni tanlang, "Permissions → Contents" ni Read and write qiling. Token faqat shu brauzeringizda (localStorage) saqlanadi, hech qayerga yuborilmaydi — faqat GitHub'ning o'ziga so'rov yuborish uchun ishlatiladi.
